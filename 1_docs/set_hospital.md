### 萬芳醫院處理建議

萬芳醫院的 `wwww.wanfang.gov.tw/robots.txt` 設定 `Disallow: /`（全站禁止爬蟲）。建議措施：

1. **降低爬蟲頻率**：從 60 秒改為 300 秒
2. **加入 User-Agent 標示**：使用辨識性的 UA 如 `DingDonBot/1.0`
3. **尊重 robots.txt**：若收到醫院方面要求，隨時停止
4. **考慮替代方案**：聯繫萬芳醫院 IT 部門，詢問是否有官方 API 可用

### 整體爬蟲策略

| 策略 | 內容 |
|------|------|
| 爬蟲頻率 | 一般 60 秒，萬芳 300 秒，政府 API 300 秒 |
| User-Agent | 標示為 `DingDonBot/1.0 (+叮咚到號看診進度通知)` |
| 錯誤處理 | 3 次失敗自動降頻至 5 分鐘 |
| 運作時段 | 僅看診時段（週一至週六 7:00-21:30） |
| 資料用途 | 僅讀取公開的即時看診進度，不取個資 |
| 快取策略 | Redis 快取 5 分鐘，減少重複請求 |
