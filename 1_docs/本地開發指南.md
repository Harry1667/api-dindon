# 叮咚到號 — Win11 本地開發指南

## 前置條件

- ✅ Docker Desktop for Windows（已安裝）
- ✅ Git（推薦）
- 🔲 ngrok（LINE webhook 測試用，免費帳號即可）

---

## Step 1：啟動所有服務

打開 PowerShell，進入專案資料夾：

```powershell
cd medical-queue-notify
docker compose -f docker-compose.dev.yml up --build
```

> 第一次會比較久（下載 image + pip install），之後都是秒啟

等看到以下 log 就代表成功：

```
medqueue-app    | INFO:     Uvicorn running on http://0.0.0.0:8000
medqueue-worker | [INFO] celery@... ready.
medqueue-beat   | [INFO] beat: Starting...
```

---

## Step 2：驗證服務是否正常

### 2a. 測試 API

瀏覽器打開：http://localhost:8000

應該看到 JSON 回應。

### 2b. 測試爬蟲

開新的 PowerShell 視窗：

```powershell
docker exec medqueue-worker python -c "
from app.scrapers.registry import adapter_registry
import asyncio

async def test():
    adapter = adapter_registry.get_adapter('wanfang')
    results = await adapter.fetch_progress()
    for r in results[:3]:
        print(r.format_message())

asyncio.run(test())
"
```

應該能看到萬芳醫院的看診進度資料。

### 2c. 確認 MySQL 資料表

```powershell
docker exec -it medqueue-mysql mysql -u dindon -pdindon123 dindon -e "SHOW TABLES;"
```

## Step 3：設定 ngrok（LINE Webhook 測試）

LINE 的 webhook 需要 HTTPS 公開網址。本地開發用 ngrok 轉發。

### 3a. 安裝 ngrok

去 https://ngrok.com 註冊免費帳號，下載 Windows 版，解壓後設定 token：

```powershell
ngrok config add-authtoken 你的TOKEN
```

### 3b. 啟動 ngrok

```powershell
ngrok http 8000
```

會拿到像這樣的網址：
```
Forwarding  https://xxxx-xxx-xxx.ngrok-free.app -> http://localhost:8000
```

### 3c. 更新 LINE Webhook URL

1. 打開 LINE Developers Console：https://developers.line.biz
2. 進入你的 Channel → Messaging API
3. 把 Webhook URL 改成：

```
https://xxxx-xxx-xxx.ngrok-free.app/api/webhook
```

4. 點「Verify」驗證 ✅
5. 打開「Use webhook」

> ⚠️ ngrok 每次重啟網址會變，需要重新設定 LINE webhook URL

## Step 4：用 LINE 測試

1. 打開 LINE App
2. 掃描你的 LINE Official Account QR Code 加入好友
3. 送出訊息測試：

| 輸入 | 預期回覆 |
|------|----------|
| `說明` | 使用說明 |
| `萬芳 精神科` | 精神科看診進度 |
| `萬芳 282診` | 282 診的看診進度 |
| `追蹤 萬芳 精神科 許元彰 我是60號` | 開始追蹤，快到時推播 |
| `我的追蹤` | 列出追蹤清單 |
| `取消追蹤` | 取消所有追蹤 |

## 常用指令

```powershell
# 啟動（背景執行）
docker compose -f docker-compose.dev.yml up -d --build

# 看 log
docker compose -f docker-compose.dev.yml logs -f

# 只看某個服務
docker compose -f docker-compose.dev.yml logs -f app
docker compose -f docker-compose.dev.yml logs -f worker

# 停止所有服務
docker compose -f docker-compose.dev.yml down

# 停止並清除資料（包含 MySQL 資料）
docker compose -f docker-compose.dev.yml down -v

# 重建某個服務
docker compose -f docker-compose.dev.yml up -d --build app
```

---

## 開發流程

1. 改 Python 程式碼 → FastAPI 自動 reload（app 服務）
2. 改 Celery worker/beat 的程式碼 → 需要重啟 worker/beat：
   ```powershell
   docker compose -f docker-compose.dev.yml restart worker beat
   ```
3. 改了 requirements.txt → 需要重新 build：
   ```powershell
   docker compose -f docker-compose.dev.yml up -d --build
   ```

---

## 從本地到正式環境

本地測試 OK 後，上 VPS 只需要：

1. 把程式碼上傳到 VPS
2. 使用 `docker-compose.yml`（正式版，不含 MySQL）
3. 使用 `.env`（正式版，MySQL 指向 aaPanel）
4. 設定 Nginx + SSL
5. 把 LINE Webhook URL 改成正式網域 `https://dindon.cleanhome.tw/api/webhook`
