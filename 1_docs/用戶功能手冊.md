# 叮咚到號 — 用戶功能與邏輯手冊

> 最後更新：2026-03-31
> 涵蓋：所有用戶可操作的功能、系統自動行為、對話狀態機

---

## 一、快捷指令總覽

| 指令 | 功能 | 任何狀態可用 |
|------|------|:---:|
| `@` 或 `0` 或 `#` | 回主選單 | ✅ |
| `h` 或 `說明` | 顯示使用說明 | ✅ |
| `00` 或 `醫院` 或 `列表` | 顯示支援的醫院清單 | ✅ |
| `t` 或 `追蹤` | 查看目前追蹤（含即時進度） | ✅ |
| `c` 或 `取消追蹤` | 取消所有追蹤 | ❌ 流程中不觸發 |
| `p` 或 `預約` | 預約追蹤 | ❌ 流程中不觸發 |
| `/` 或 `返回` | 返回上一層 | 部分狀態 |
| `1` `2` `3` | 選擇選項（依上下文） | 部分狀態 |

> 在多步驟流程中（預約追蹤、選醫院等），`c` `t` `p` 不會打斷流程，只有 `@` 和 `h` 可以跳出。

## 二、核心功能

### 2.1 查詢看診進度

**觸發方式：** 直接輸入醫院名稱

```
用戶: 台大醫院
用戶: 長庚
用戶: 馬偕
用戶: 台大 骨科      ← 可加科別篩選
```

**流程：**

```
輸入醫院名 → 別名匹配
  ├── 匹配到 1 家 → 顯示看診中科別列表（前 20 科）
  ├── 匹配到多家（如「長庚」）→ 列出所有匹配醫院讓用戶選
  └── 找不到
       ├── 含中文 2 字以上 → 「找不到 XXX，輸入 00 查看支援醫院」
       └── 打招呼/閒聊 → 歡迎訊息 + 主選單
```

**科別列表顯示規則：**
- 超過 20 科時只顯示前 20 科，提示「還有 N 科，輸入科別關鍵字篩選」
- 科別名過長時截短（去掉位置資訊如「-第二門診六樓」）
- 常用科別標記 ⭐

**選科後流程：**
```
選科（輸入數字或科名） → 顯示該科所有醫師的看診進度
  → 選項：1.追蹤 2.查詢別科 3.返回主選單
```

### 2.2 追蹤掛號（即時通知）

**建立方式 A：查詢後追蹤**
```
查詢醫院 → 選科 → 選醫師 → 選「追蹤」→ 輸入掛號號碼 → 選通知模式
```

**建立方式 B：快速追蹤**
```
用戶: 萬芳 下午 303診 8
→ 直接進入選通知模式，不需一步步選
```

**建立方式 C：預約追蹤（`p`）**
```
p → 輸入醫院 → 選時段 → 輸入科別 → 輸入醫師 → 輸入號碼 → 選模式
→ 看診開始後系統自動監控
```

**號碼驗證：** 1~9999

**通知模式：**

| 模式 | 指令 | 觸發條件 | 適用場景 |
|------|------|---------|---------|
| 📢 每號提醒 | `1` | 每次叫號變動都通知 | 需要密切關注 |
| 🔔 輕量提醒 | `2`（推薦） | 剩 10、5、3、1、0 號 | 一般使用 |
| 🔕 最後提醒 | `3` | 剩 3 號內才通知 | 不想被打擾 |

**所有模式共同：首次建立追蹤後，一定會通知一次**（讓用戶知道系統在運作）。

### 2.3 查看追蹤狀態（`t`）

**回覆格式：**
```
🔔 您目前的追蹤：

📢 萬芳醫院 消化系內科 粟發滿 309診
   你是第 35 號，目前第 19 號，還有 16 位

📢 萬芳醫院 家庭醫學科 陳宣宇 372診
   你是第 30 號，目前第 25 號，還有 5 位

輸入 c 取消所有追蹤
```

如果 Redis 暫時無該醫師資料，顯示「暫無即時資料」。

### 2.4 取消追蹤（`c`）

取消該用戶所有 ACTIVE 的追蹤任務。

### 2.5 常用醫院快捷

主選單會記住用戶最常查詢的醫院，顯示在底部：
```
⭐ 常用醫院（輸入數字快速查詢）：
  1. 萬芳醫院
  2. 台大醫院
  3. 馬偕醫院(台北)
```

## 三、系統自動行為

### 3.1 通知推播（每 60 秒檢查）

**觸發條件（依模式）：**

| 模式 | 首次 | 後續 |
|------|------|------|
| 每號提醒 | 一定通知 | 每次號碼變動 |
| 輕量提醒 | 一定通知 | 剩 10→5→3→1→0 號 |
| 最後提醒 | 一定通知 | 剩 ≤3 號後每次變動 |

### 3.2 到號通知

```
目前號碼 == 你的號碼 → 「🔔 輪到您了！」→ 追蹤自動結束
```

### 3.3 過號處理

```
目前號碼 > 你的號碼 → 「⚠️ 您的號碼可能已過號」
  → 不自動結束（可能是跳號）
  → 過號超過 30 分鐘 → 自動結束追蹤
```

### 3.4 醫院端過號標記

```
醫院標記你的號碼為「過號」→ 「⚠️ 您的號碼已被叫到但標記過號！」
  → 提醒儘速報到
```

### 3.5 看診結束自動清理

```
已通知過 + Redis 無該醫師資料 + 建立超過 2 小時
  → 「ℹ️ 看診已結束，追蹤自動結束」
```

### 3.6 預約追蹤超時

```
從未通知 + 建立超過 12 小時
  → 「ℹ️ 已超過 12 小時未偵測到看診資料」→ 追蹤結束
```

### 3.7 追蹤結束回饋

追蹤結束後，系統會詢問：
```
📋 追蹤結束，通知是否正確？
  0 — ✅ 正確
  1 — ❌ 有誤
```

```

         │         └────┬────┘          │
         │              │               │

         │              │               │
         ▼              ▼               ▼

  │ 匹配醫院  │  │ pretrack_  │
  └────┬─────┘  │ hospital   │
       │        └──┬─────────┘
       │           │ 選醫院
  ┌────▼─────┐  ┌──▼─────────┐

  │ session  │  │ session    │

  └────┬─────┘     │ 選時段
       │        ┌──▼─────────┐
  ┌────▼─────┐  │ pretrack_  │
  │ choose_  │  │ dept       │
  │ dept     │  └──┬─────────┘
  │（選科別） │     │ 輸入科別
  └────┬─────┘  ┌──▼─────────┐
       │        │ pretrack_  │
  ┌────▼─────┐  │ doctor     │
  │ choose_  │  └──┬─────────┘
  │ doctor   │     │ 輸入醫師

  ┌────▼──────┐ └──┬─────────┘

  │ result    │ ┌──▼─────────┐

  └────┬──────┘ │ mode       │
       │        └──┬─────────┘
  選「追蹤」       │ 選模式
       │           │
  ┌────▼──────────▼──────┐
  │ waiting_track_number │ ← webhook 接手
  └────┬─────────────────┘
       │ 輸入號碼
  ┌────▼─────────────────┐
  │ waiting_track_mode   │
  └────┬─────────────────┘
```

## 六、錯誤處理

| 情境 | 系統回覆 |
|------|---------|
| 找不到醫院（含中文） | 「🔍 找不到 XXX，輸入 00 查看支援醫院」 |
| 系統處理失敗 | 「抱歉，系統暫時忙碌中，請稍後再試 🙏」 |
| 訊息超過 500 字 | 「訊息過長，請縮短後再試」 |
| 號碼超出 1~9999 | 「號碼範圍 1~9999，請重新輸入」 |
| 預約流程中找不到醫院 | 「🔍 找不到 XXX，輸入 00 查看列表」 |
| 打招呼（你好、嗨） | 歡迎訊息 + 主選單 |

## 八、爬蟲與資料更新

| 項目 | 頻率 |
|------|------|
| 看診進度抓取 | 每 60 秒（28 家醫院輪流） |
| 通知檢查 | 每 60 秒（獨立 queue，不被爬蟲擋住） |
| Redis 快取 TTL | 10 分鐘（MERGE 模式，不清除舊資料） |
| 無資料醫院降頻 | 連續 3 次空結果 → 每 5 分鐘才抓一次 |
| 爬蟲失敗告警 | 連續 3 次失敗 → LINE 通知管理員 |

## 九、追蹤生命週期

```
建立追蹤（ACTIVE）
     │
     ├── 首次通知（一定觸發）
     │
     ├── 號碼變動通知（依模式）
     │
     ├── 到號 → NOTIFIED + 問回饋 → 結束
     │
     ├── 過號 → 通知用戶
     │    └── 30 分鐘後 → 自動結束（passed）
     │
     ├── 醫師無資料 + 超過 2 小時 → 自動結束（doctor_gone）
     │
     ├── 從未通知 + 超過 12 小時 → 自動結束（timeout）
     │
     └── 用戶取消（c）→ CANCELLED
```

## 十、Admin 後台

URL: `https://dindon.cleanhome.tw/admin`

| API | 功能 |
|-----|------|
| `/admin/api/stats` | 基本統計（醫院數、用戶數、追蹤數） |
| `/admin/api/dashboard` | 增強版：活躍用戶、醫院排行、爬蟲成功率、通知數、漏斗 |
| `/admin/api/feedbacks` | 用戶回饋列表 |
| `/admin/api/hospitals` | 醫院管理（啟用/停用） |
| `/admin/api/test/run` | 執行自動測試 |
