# 你需要做的事 — 部署前準備 & 操作手冊

> 以下是需要你親自操作的步驟，我無法代你完成（需要帳號登入、密碼設定等）。
> 程式碼部分已全部完成，在 `medical-queue-notify/` 目錄中。

---

## 第一步：建立 LINE Official Account + Messaging API

### 1.1 註冊 LINE Developers 帳號

1. 前往 https://developers.line.biz/zh-hant/
2. 用你的 LINE 帳號登入
3. 建立一個 Provider（例如「醫院掛號通知」）

### 1.2 建立 Messaging API Channel

1. 在 Provider 下點擊「Create a new channel」
2. 選擇 **Messaging API**
3. 填寫資料：
   - Channel name：`叮咚到號`
   - Channel description：`醫院看診進度即時查詢，掛號快到自動通知你`
   - Category：`健康`
   - Subcategory：`醫療`
4. 建立完成

### 1.3 取得金鑰（填入 .env）

在 Channel 設定頁面中取得：

| 項目 | 位置 | 對應 .env 變數 |
|------|------|---------------|
| Channel secret | Basic settings → Channel secret | `LINE_CHANNEL_SECRET` |
| Channel access token | Messaging API → 點「Issue」產生 | `LINE_CHANNEL_ACCESS_TOKEN` |

### 1.4 設定 Webhook

在 Messaging API tab 中：

1. **Webhook URL** 設為：`https://你的域名/webhook`
2. 開啟 **Use webhook**
3. 關閉 **Auto-reply messages**（在 LINE Official Account Manager 中）
4. 關閉 **Greeting messages**（或保持開啟，系統會自動回覆說明）

## 第二步：VPS + aaPanel 環境準備

### 2.1 VPS 需求

- 建議規格：2 核 / 4GB RAM / 40GB SSD
- 作業系統：Ubuntu 22.04 LTS
- 需要安裝 aaPanel

### 2.2 aaPanel 安裝必要軟體

在 aaPanel 的「App Store」中安裝：

1. **Nginx**（任意版本）
2. **MySQL 8.0**
3. **Docker Manager**（如果面板有的話，否則 SSH 手動裝）

### 2.3 安裝 Docker & Docker Compose

如果 aaPanel 沒有 Docker 插件，SSH 登入執行：

```bash
# 安裝 Docker
curl -fsSL https://get.docker.com | sh
systemctl enable docker
systemctl start docker

# 安裝 Docker Compose（新版已內建）
docker compose version
```

### 2.4 建立 MySQL 資料庫

在 aaPanel → Database 中：

1. 新增資料庫：
   - 名稱：`medical_queue`
   - 用戶名：`medqueue`
   - 密碼：**自己設定一個強密碼**
   - 字元集：`utf8mb4`
2. 設定權限：允許 `localhost` 和 `172.17.0.0/16`（Docker 內部網段）

或者用 MySQL 命令列：

```sql
CREATE DATABASE medical_queue CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'medqueue'@'%' IDENTIFIED BY '你的密碼';
GRANT ALL PRIVILEGES ON medical_queue.* TO 'medqueue'@'%';
FLUSH PRIVILEGES;
```

> ⚠️ 注意：因為 Docker 容器連線 MySQL 時是透過 Docker bridge IP，
> 所以 MySQL 用戶權限需要允許非 localhost 連線。
> 如果安全考量，可以限定為 `172.17.0.0/16`。

## 第三步：部署應用

### 3.1 上傳程式碼

將 `medical-queue-notify/` 整個目錄上傳到 VPS，例如放在：

```
/www/wwwroot/medical-queue-notify/
```

### 3.2 建立 .env 檔案

```bash
cd /www/wwwroot/medical-queue-notify/
cp .env.example .env
nano .env
```

填入你的實際值：

```env
LINE_CHANNEL_SECRET=你的Channel Secret
LINE_CHANNEL_ACCESS_TOKEN=你的Channel Access Token
MYSQL_HOST=host.docker.internal
MYSQL_PORT=3306
MYSQL_USER=medqueue
MYSQL_PASSWORD=你設定的MySQL密碼
MYSQL_DATABASE=medical_queue
REDIS_URL=redis://redis:6379/0
```

### 3.3 啟動 Docker Compose

```bash
cd /www/wwwroot/medical-queue-notify/

# 建置映像（第一次需要）
docker compose build

# 啟動所有服務
docker compose up -d

# 檢查狀態
docker compose ps

# 查看日誌
docker compose logs -f
```

正常啟動後你應該會看到 4 個容器都是 `Up` 狀態：
- `medqueue-app` (FastAPI)
- `medqueue-worker` (Celery Worker)
- `medqueue-beat` (Celery Beat)
- `medqueue-redis` (Redis)

### 3.4 驗證服務

```bash
# 健康檢查
curl http://localhost:8000/health
# 應該回傳: {"status":"ok","version":"0.1.0"}
```

## 第四步：設定 Nginx 反向代理 + SSL

### 4.1 在 aaPanel 中新增網站

1. aaPanel → Website → Add site
2. 域名：`你的域名`
3. 不需要 PHP / 資料庫

### 4.2 設定 SSL

1. 在網站設定中 → SSL → Let's Encrypt
2. 申請免費 SSL 憑證
3. 開啟強制 HTTPS

### 4.3 設定反向代理

在網站設定中 → Reverse proxy → Add：

```
代理名稱: medqueue
目標URL: http://127.0.0.1:8000
```

或直接修改 Nginx 配置：

```nginx
location /webhook {
    proxy_pass http://127.0.0.1:8000/webhook;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location /health {
    proxy_pass http://127.0.0.1:8000/health;
}
```

### 4.4 回到 LINE Developers 設定 Webhook URL

設定為：`https://你的域名/webhook`

點「Verify」測試連線，應該顯示 Success。

## 第五步：測試

### 5.1 加入 LINE 好友

1. 在 LINE Developers → Messaging API tab 中找到 QR code
2. 用手機 LINE 掃描加入好友
3. Bot 應該自動回覆使用說明

### 5.2 測試查詢

在 LINE 中輸入：

```
萬芳 精神科
```

```
03/28 15:24 萬芳醫院-精神科 許元彰 282診 目前45號 46下一號
```

### 5.3 測試追蹤

```
追蹤 萬芳 精神科 許元彰 我是60號
```

# 更新程式碼後重新部署

## 故障排除

| 問題 | 可能原因 | 解決方式 |
|------|---------|---------|
| LINE Webhook Verify 失敗 | Nginx/SSL 沒設好 | 確認 `curl https://你的域名/health` 有回應 |
| Bot 不回覆 | Channel secret/token 錯誤 | 檢查 .env 中的 LINE 設定 |
| 查詢無結果 | 爬蟲還沒跑或非看診時段 | 檢查 worker 日誌，確認爬蟲有在執行 |
| MySQL 連不上 | 權限或 IP 限制 | 確認 MySQL 用戶允許 Docker 網段連線 |
| 容器不斷重啟 | .env 缺少或格式錯 | `docker compose logs app` 看錯誤訊息 |
